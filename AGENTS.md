# Agent Instructions & Guidelines

## Problem Template Generation
- When generating problem templates (such as in `neetcode_150/` or other practice modules):
  - Do **not** provide the actual solution implementation inside the function.
  - Leave the function body as a stub with `pass` and a comment like `# TODO: Implement solution`.
  - Include the problem statement, examples, expected time/space complexity in the module docstring, along with type hints and test cases (`assert`) in the `if __name__ == "__main__":` block.
